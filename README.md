# 🏠 PG Connect – Find Your Perfect PG Accommodation

**PG Connect** is a web-based application designed to help students and working professionals find suitable Paying Guest (PG) accommodation when moving to a new city for education or employment.

The platform connects PG owners with people searching for accommodation, making it easier to explore available properties, compare rental options, check facilities, and submit booking requests through a single platform.

## 🚀 Project Overview

Finding affordable and convenient accommodation in an unfamiliar city can be challenging. PG Connect aims to simplify this process by providing a centralized platform where users can search for PG accommodations based on their preferences, while property owners can manage their listings and booking requests.

## ✨ Key Features

- **User Authentication:** Separate login access for students/tenants and PG owners.
- **PG Listings:** Add and manage PG properties, rooms, and bed availability.
- **Search and Filters:** Search accommodations by city, area, rent, deposit, and room type.
- **Facilities Information:** View available amenities and property details.
- **Location Preferences:** Explore properties based on nearby landmarks and estimated commute information.
- **Owner Dashboard:** Manage property listings and review booking requests.
- **Booking Management:** Submit booking requests and allow owners to approve or reject them.
- **User-Friendly Interface:** Simple web interface designed to make accommodation discovery easier.

## ⚙️ Installation and Setup

Follow these steps to run PG Connect locally on your computer.

### 1. Clone the repository

```bash
git clone https://github.com/omkar2401/PG_Connect.git
```

### 2. Navigate to the project folder

```bash
cd PG_Connect
```

### 3. Create a virtual environment

```bash
python -m venv .venv
```

### 4. Activate the virtual environment on Windows

```bash
.venv\Scripts\activate
```

### 5. Install dependencies

```bash
pip install -r requirements.txt
```

### 6. Run the application

```bash
python app.py
```

### 7. Open the application

Open your browser and visit:

```text
http://127.0.0.1:5000
```

**Note:** The application may require database initialization or configuration before its first run, depending on the implementation.
